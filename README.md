# Fruit fly simulation tutorials

Welcome to the Turaga lab/Macke lab fruit fly simulation tutorial library! See
the `visual_system_tutorial` directory to get started with visual system
modeling, see the `body_tutorial` directory to get started with body modeling,
and see the `connectomics_tutorial` directory to get started with connectome
analysis. The `body_tutorial_dev_utils` directory contains development files
that aren't intended to be used as teaching material, but feel free to look
through them if you're curious.
